Screen and physical format

Choose by content

Small screens suit a simple message. Larger screens provide more area for demonstrations, captions, plans or detailed visuals, while increasing the finished pack size.

Compare screen sizes

Approve the actual module

Diagonal size alone does not define resolution, viewing angle, brightness or module layout. Record the exact quoted screen and review it in a physical sample.

Design from the dieline

The screen window, folds, buttons, speaker, charging port and safe print areas must match the approved construction.

Review artwork requirements

Media file and playback decisions

Format and codec

MP4 is a common planning format. Confirm codec, resolution, aspect ratio, frame rate, audio and final module compatibility before loading.

File order

Record the number of videos, filenames, playback order, loop behavior and which button opens each file. Avoid changing names after approval.

Readable content

Match orientation to the screen, keep captions large, use strong contrast and test important detail on the physical display rather than a desktop monitor alone.

Memory rule: select storage from the encoded size of the final approved files, not duration alone. Codec, bitrate, audio and resolution all influence file size.

Specification questions

What specifications are needed for a video brochure quote?

Provide the finished format, screen size, quantity, video duration, memory needs, playback controls, cover, print finish, packaging, destination and deadline.

Which video file format should we supply?

MP4 is a common planning format, but codec, resolution, aspect ratio, audio and final compatibility should be checked against the selected screen module before loading.

How is video brochure memory selected?

Memory should be selected after the final number, duration and encoded size of the approved files are known, with room for the required playback behavior.

Are all screens and charging ports the same?

No. Screen resolution, panel type, viewing angle, brightness, module layout and charging interface can vary. Confirm the exact module in the quotation and physical sample.
