How to Upload or Change the Video on a Video Brochure

Most video brochures with a USB port can be updated from a computer in a few minutes. Follow these steps to replace the video safely and check that it plays correctly.

Get pricingRequest a sample

Quick answer: Connect the video brochure to a computer with a USB data cable, open it as a removable drive, back up the existing files, copy your new MP4 video, safely eject it and test playback. Whether a model supports updates depends on its module, so confirm this when ordering.

Before you start

You need a computer, the USB cable supplied with the brochure (some charging-only cables do not carry data), and your video exported as an MP4 file. Charge the brochure before updating. Check the file format, resolution and maximum file size that were confirmed for your module, as these vary between screen sizes. The specification guide lists what to confirm.

Step-by-step: replace the video

Switch on and connect. Open the brochure so the module is powered, then connect it to the computer with the USB data cable.
Open the drive. The brochure usually appears as a removable drive in File Explorer (Windows) or Finder (Mac). If it only charges, try another cable or USB port.
Back up the existing files. Copy the current video files to your computer before changing anything, so you can restore them if needed.
Copy the new video. Delete or replace the old file and copy your new MP4. Keep file names simple, using letters and numbers only.
Set the playback order. For brochures with chapter buttons, playback often follows file names, so name files 01, 02, 03 in the order the buttons should play them.
Eject safely and test. Use Eject (Mac) or Safely Remove Hardware (Windows), disconnect, then close and reopen the brochure to test playback, sound and every button.

Frequently asked questions

Can you change the video on a video brochure?

Yes, on most models with a USB data port. Connect it to a computer, open it as a removable drive and replace the MP4 file. Whether a specific model supports updates depends on its module.

What video format does a video brochure use?

MP4 is the most widely supported format. Use H.264 video and AAC audio at the resolution confirmed for the screen size of your module.

Why does my computer not detect the video brochure?

The most common causes are a charge-only USB cable, the module being switched off because the cover is closed, or a module that does not support USB updates.

How do I set the order of videos for chapter buttons?

Playback order commonly follows file names. Name files 01, 02, 03 and so on in the order the buttons should play them, then test each button.

Does Video Brochure Plus load the video for us?

Yes. Approved video files are preloaded and tested before shipment, so brochures arrive ready to play.
